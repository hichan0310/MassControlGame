# 도구

모두 저장소 루트에서 실행한다. Node.js 18 이상, Python 3 필요. 브라우저 캡처만 Playwright 가 필요하다.

## 시뮬레이션 (`tools/sim`)
화면 없이 게임 코드를 Node 에서 그대로 돌린다. `index.html` 을 고칠 때마다 먼저 `extract.py` 로 다시 뽑을 것.

| 파일 | 하는 일 |
|---|---|
| `extract.py` | `index.html` → `build/game.js`(원본), `build/game_i.js`(계측판: 피격 훅, 시간·딜 기록 노출) |
| `harness.js` | 가짜 캔버스·DOM·키 입력·rAF. `require('./harness')('game.js')` → `{M, fire, step, T}` |
| `smoke.js` | 2분 회귀 점검. 무기 8종 최대 + 진화 4개, 최악·평균 프레임 시간 출력 |
| `bot.js` | 봇으로 한 판. 모드 `pro`(숙련 돌진형, `pro.js`), `proevade`(같은 판단으로 피하기만), `ram`(옛 돌진형: 작게 가속 → 충돌 직전 커짐, 에너지 낮으면 회복), `evade`(회피형: 예측 회피 + 안전한 구슬 줍기, `EVSZ=n` 이면 최소 크기+n 유지), `kite`(옛 회피형, 기준으로 부적합), `noweap`(무기 카드 기피) |
| `pro.js` | 숙련 돌진형 봇 (충전 ↔ 돌격 사이클, 부술 수 있는 적만 노림, 적탄·폭탄병·포위 회피, 카드 판단). 사람 기준 "10분 이상 버티는 돌진 플레이"에 맞춤 |
| `stance.sh` | 숙련 돌진형(`pro`) vs 숙련 회피형(`proevade`) 같은 시드·같은 카드 판단으로 비교 → 생존·처치·점수 표 (`stance_agg.py`). `SEEDS="..."` 로 시드 지정, 비교는 20판 이상 |
| `matrix.sh` | 무기 8 단독 + 진화 28 을 후반 모의(적 체력 30배, 무적 봇, 2분×시드 2개)로 돌려 8×8 표 |
| `agg.py` | `matrix.sh` 결과 폴더 → 8×8 표 출력 |
| `screenshot.py` | 실제 Chrome 으로 장면 캡처 (`pip install playwright && playwright install chromium`) |

### `bot.js` 환경 변수
| 변수 | 의미 |
|---|---|
| `W=무기키` | 그 무기만 들고 시작 (`LV=1` 이면 1레벨, 없으면 최대) |
| `EVK=a+b` | 그 진화 + 재료 무기 최대로 시작 |
| `LATE=1 HM=30` | 무적 + 적 체력 HM배 + 10초마다 60마리 투입 — 강한 조합끼리도 차이가 나는 측정 |
| `SMART=1` | `pro` 가 아닌 봇도 카드를 `pro.js` 방식으로 고름 |
| `FLEE=rep\|gap` `REC=0.3` | `pro` 의 충전 중 도주 방식(밀어내기/빈틈 찾기)과 충전 시작 에너지 비율 |
| `RES=1` | 마지막에 `RES {...}` 요약 한 줄(생존·처치·레벨·점수·몸통 비중·받은 피해) |
| `DUMMY=1` | 무적 + 죽지 않는 표적 150마리 — 잠재 화력 (밀집 범위 공격이 과대평가됨) |

출력(W/EVK 모드) 첫 줄 JSON: `wdps`(무기·진화 초당 피해), `share`(무기 몫 %), `core`(몸통 충돌+당구+체렌코프 %), `surv`(생존 분), `dead`, `kills`.

### 측정 시 주의
- 랜덤 봇이라 같은 조건도 ±15~20% 흔들린다. 시드 2개 이상, 차이가 작으면 결론 내지 말 것.
- 적이 금방 다 죽는 조건에서는 강한 조합끼리 수치가 천장에 막힌다 → `LATE=1 HM=30` 사용.
- 봇은 사람처럼 포위를 읽지 못하므로 **생존 시간은 실제보다 짧다.** 피해 비중 비교용으로 쓸 것.

## 강화학습 (`tools/rl`)
전략은 알려주지 않고 **조작 틀만 고정**한 순수 강화학습(PPO)이다. 게임은 Node 에서 화면 없이 돌리고, 학습은 PyTorch(GPU)로 한다.

### 준비 (처음 한 번)
```bash
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r tools/rl/py/requirements.txt
```

### 실행
```bash
.venv/bin/python tools/rl/py/train.py --name run1            # 학습. 회차마다 한 줄 기록, 10회차마다 카드 선택률. Ctrl-C = 저장 후 종료
.venv/bin/python tools/rl/py/train.py --name run1 --resume   # 이어서
.venv/bin/python tools/rl/py/eval.py run1                    # 평가: 24판 끝까지 (생존·레벨·몸통딜·고른 카드)
node tools/rl/check.js run1                                  # JS 추론이 PyTorch 와 같은 값인지
MODEL=run1 node tools/sim/bot.js rl 301 15                   # 한 판 자세히 (딜 출처·받은 피해 원인)
```
브라우저 관전: `index.html#bot=rl&model=run1&speed=2` (`model` 생략하면 가장 최근 저장본, `&greedy=1` 이면 최선 행동만). 10회차마다 저장되므로 새로고침하면 최신 모델.

### 다른 컴퓨터도 같이 쓰기 (`--remote`)
게임 시뮬레이션(CPU)이 병목이므로, 다른 컴퓨터는 게임만 돌리고 학습(GPU)은 이 컴퓨터가 한다. 학습기가 SSH 로 그쪽 `envserver.js` 를 띄우고 표준 입출력으로 주고받는다.
```bash
.venv/bin/python tools/rl/py/train.py --name mix1 --reward mix --resume --remote laptop:48           # 노트북에서 48판 더
.venv/bin/python tools/rl/py/train.py ... --remote laptop:48:6:~/MassControlGame                     # 호스트:판수:서버수:폴더
```
- 그 컴퓨터에 필요한 것: Node 18+, Python 3(추출 스크립트용), **같은 버전의 저장소**(다르면 관측 사양 불일치로 멈춤), 이 컴퓨터에서 비밀번호 없이 `ssh 호스트` 로 들어가지는 SSH 키 접속. PyTorch 는 필요 없음.
- 판 수는 그 컴퓨터 코어 수 × 4 정도. 회차 속도는 가장 느린 컴퓨터에 맞춰지므로 유선 랜을 권장 (판 48개면 걸음마다 약 400KB).

### 행동 (게임이 바뀌어도 그대로)
- 이동 9(8방향 + 정지) × 크기 3(줄이기·유지·키우기) = 27, 4프레임마다 결정
- 카드: 제시된 후보 중 하나 (카드마다 학습되는 고유 벡터 + 카드 특징 + 상황으로 점수)

### 관측 (`features.js`) — 게임 메커니즘에 맞춤
| 구간 | 내용 |
|---|---|
| 내 상태 | 속도(체렌코프 임계 1150·현재 크기 최고 속도·화염 임계 480 대비), 크기·질량, **지금 박으면 나올 충격량 ÷ 스킬 임계값**(번개·탄환 250, 충돌 폭발 3000), 에너지·소모율·충전 구간, 체력, 레벨·경험치, 벽까지 거리, 연속 처치·관통, 무기 타이머(번개 대기·미사일·지뢰·블랙홀), 특수 능력 조건(초신성 준비, 밀도 압축 0.45초 창·재충전, 중력 우물 재충전, 조석력 활성), `U` 의 모든 수치(카드 효과 배율, 자동), 카드별 보유 상태(자동) |
| 적 40 (토큰) | 위치, 상대 속도, 다가오는 속도, 접촉까지 시간(지금 크기 / 커졌을 때), **지금 박으면 부술 수 있나**(현재 크기 / 최대 크기), 날아가는 중, 돌진병 조준·돌진, 사수 발사 타이머, 자기장 안인지, 종류(자동) |
| 적탄 12 · 바위 6 · 내 블랙홀·지뢰 10 (토큰) | 적탄은 최근접 시각·빗나가는 거리까지 |
| 레이더 | 나를 중심으로 12방향 × 4거리(1400 까지): 적 수·체력·구슬·적탄·바위/벽 — 어느 방향이 비었는지 |
| 미니맵 | 맵 전체 400px 칸(14×9): 적 수·체력·구슬 — 멀리 어디로 빠질지 |
| 카드 후보 3 | 카드 번호, 무기/진화/특수, 현재 레벨, 새 슬롯을 쓰는지, 최대 레벨을 채우는지 |

모든 특징은 학습 중 특징별로 크기를 맞춘다(제곱평균 정규화, 모델에 같이 저장). **새 스킬의 발동 조건을 모델에 알려주려면 `features.js` 의 `selfList` 에 한 줄 추가.** 적 종류·카드·`U` 수치는 자동으로 읽는다. 관측이 바뀌면 이어 학습은 안 되고 새 이름으로 학습해야 한다.

### 모델 (`py/model.py`)
나·적·적탄·바위·블랙홀/지뢰를 토큰으로 트랜스포머(2층, 4헤드, 128차원)에 넣어 개체 사이 관계를 보고, 레이더·미니맵·내 상태는 따로 요약 → 줄기 MLP → 이동 27 / 가치 / 카드 점수. 비교용으로 `--arch mlp`(관측 전체를 MLP)도 있다.
- `py/model.py` 를 바꾸면 JS 추론 `net.js` 도 같이 바꾸고 `node tools/rl/check.js 이름` 으로 확인.

### 학습 (`py/train.py`)
PPO, 96판 동시(Node 서버 12개 × 8스레드), 회차당 12,288 걸음, 할인율 0.999(≈1분 앞까지 — 카드 효과처럼 늦게 나타나는 것), bf16 혼합 정밀도. 12코어 + RTX 4060 Ti 에서 회차당 약 3.3초(초당 약 3,700 걸음, 시간당 약 1,300만).
- 보상: 기본 `survive`(살아 있던 시간만). `--reward score` · `mix`.
- 기록 `tools/rl/models/이름.csv`: 생존(분)·레벨·처치·몸통딜 %·직접박기 %·엔트로피·KL. 10회차마다 화면에 **카드 선택률**(제시됐을 때 고른 비율) — 모델이 어떤 카드를 좋다고 보는지.
- 주요 옵션: `--envs 96` `--servers 12` `--steps 128` `--lr 3e-4` `--gamma 0.999` `--ent 0.01` `--ent-card 0.03` `--d 128 --layers 2` `--arch attn|mlp` `--no-amp`.
- 초반 확인값(참고): 74만 걸음에서 평균 생존 약 1.1~1.2분(무작위 0.4분). 숙련 돌진형 봇(평균 12.3분)에 닿으려면 수천만~억 걸음 단위가 필요할 수 있다.

## 봇 관전 (브라우저)
`index.html` 주소 뒤에 `#bot=pro` 를 붙여 열면 `tools/sim/pro.js` 봇이 대신 플레이한다. 빌드·서버 필요 없음.
- `index.html#bot=pro` — 숙련 돌진형, `index.html#bot=proevade` — 피하기만 하는 봇, `index.html#bot=rl&model=이름` — 강화학습 모델
- `&speed=2` (최대 4) — 배속. 죽으면 3초 뒤 새 판
- 키 설정을 바꿔 뒀어도 그 창에서만 기본 키로 돌아가고 저장된 설정은 그대로
