# 밸런스

## 원칙
1. **박는 재미가 우선.** 충돌로 발동하는 무기는 충돌 세기에 비례(연쇄 번개, 추가 탄환). 저절로 발동하는 무기(미사일·지뢰·자기장·위성)는 `PAS = 0.6` 배.
2. **강한 건 강해도 되지만, 약한 게 너무 약하면 안 된다.**
3. 진화는 같은 두 무기를 따로 들 때보다 확실히 세야 한다 (슬롯 1칸 절약 + 화력).

## 측정 방법
`sh tools/sim/matrix.sh` — 돌진형 봇, 무적, 적 체력 30배, 10초마다 60마리 투입, 2분 × 시드 2개.
- 대각선: 그 무기 하나만 최대 레벨. 나머지: 진화 + 재료 무기 최대 레벨.
- 값은 무기·진화가 낸 초당 피해(천 단위). 몸통 충돌·당구·체렌코프·적 폭발은 제외.
- 랜덤 봇이라 ±15~20% 흔들림.

### 읽는 법과 남은 과제
- **특이점이 전반적으로 강하다.** 단독 150, 특이점이 들어간 진화 대부분 190~490. 블랙홀 생성 확률 상향과 "안에 있는 동안 지속 피해"가 원인. 블랙홀 폭발은 이미 −30% 했다.
- **지평선 탄(탄환+특이점) 489**: 블랙홀 탄이 적을 붙잡고 멈추도록 바꾼 뒤 크게 올랐다. 가장 센 진화.
- **번개탄(번개+탄환) 87, 연쇄 기폭(미사일+지뢰) 102** 가 가장 약하다. 번개탄은 두 재료가 모두 "충돌 세기 비례"로 바뀌면서, 무적 봇 측정에서는 낮게 나온다. 실제 플레이에서 세게 박으면 더 올라갈 수 있으나 확인 필요.
- 이 표는 **후반(적 체력 30배)** 기준이다. 초반에는 미사일·지뢰처럼 여러 적을 빨리 잡는 무기가 표보다 강하게 느껴진다.

## 돌진형 vs 회피형 (박는 쪽이 이득인지)
`SEEDS="$(seq -s ' ' 201 224)" sh tools/sim/stance.sh 15` — 숙련 돌진형(`pro`)과 숙련 회피형(`proevade`)을 같은 시드·같은 카드 판단으로 비교. 15분 상한, 24판씩, 약 8분.
- `pro`(`tools/sim/pro.js`): 충전 ↔ 돌격 사이클. 에너지 30% 아래면 무리에서 벗어나 작은 몸으로 충전, 90% 차면 적에게 작게 가속 → 실제 접촉 시각을 계산해 직전에 커져서 충돌. 지금 속도로 부술 수 있는 적만 노리고 방패병·엘리트·가시는 장애물로 피함. 적탄 궤적 회피, 폭탄병이 가까우면 미리 커짐, 포위되면 빈 쪽으로 탈출. 카드는 진화 > 가진 무기 > 빈 슬롯 > 몸통 강화.
- `proevade`: `pro` 와 같은 회피·도주·크기·카드 판단을 쓰되 **먼저 노리지 않음**. 공정한 비교 상대.
**목표: 돌진형이 생존·처치·점수 모두에서 확실히 앞설 것.** 어떤 빌드·카드로 회피형이 이기면 설계 실패.

| 봇 | 평균 생존 | 10분 이상 | 평균 레벨 | 평균 처치 | 몸통 딜 % |
|---|---|---|---|---|---|
| pro (숙련 돌진) | 12.3분 | 19/24 | 32.3 | 14,911 | 20 |
| proevade (숙련 회피) | 4.9분 | 3/24 | 12.4 | 2,625 | 49 |

돌진/회피 비율 — **생존 2.5배, 처치 5.7배, 점수 2.3배** (충돌 회복·관통 반영 후).

- 옛 `ram` 봇은 평균 약 3분에 죽었다(못 부수는 방패병에 박고, 커질 에너지 없이 폭탄병 옆에서 터짐). 옛 `ram`/`evade` 로 잰 값(생존 비 1.41 → 1.66배, 충돌 회복·관통 전후)은 봇이 서툴러서 신뢰도가 낮다.
- **봇 측정 함정:** 서툰 회피 봇과 비교하면 돌진형이 수십 배 이기는 것처럼 보인다(`evade` 대비 생존 7.7배, 처치 38배). 비교 상대는 같은 판단력을 가진 `proevade` 로.
- 시드 8개로는 ±15~20% 흔들린다. **비교는 20판 이상**, 튜닝에 쓴 시드(101~112)와 다른 시드로 확인할 것.
- `pro` 의 몸통 딜 비중이 15분 판에서 20% 안팎이다(후반엔 무기 딜이 대부분). 박는 재미가 후반에 무기에 가려지는지 확인 필요.

## 몸통 비중 점검 (박는 재미를 해치는지)
`W=무기 [LV=1] node tools/sim/bot.js ram <시드> 4` 로 무기 하나만 들고 4분.
| 무기 | Lv1 무기 / 몸통 | 최대 Lv 무기 / 몸통 |
|---|---|---|
| 연쇄 번개 | 14% / 48% | 63% / 29% |
| 추가 탄환 (충돌 세기 비례 후) | 22% / 48% | 43% / 37% |
| 특이점 | 8% / 71% | 22% / 56% |
| 위성 | 9% / 64% | 33% / 42% |
| 자기장 | 14% / 57% | 24% / 41% |
| 화염 궤적 | 10% / 64% | 27% / 44% |
| 유도 미사일 | 7% / 63% | 42% / 42% |
| 지뢰 | 28% / 50% | 36% / 41% |

(이후 지뢰·위성 +30%, 블랙홀 폭발 −30%, 레일건 ×2, 항성 핵 −10% 가 반영되었음. 다시 측정 권장.)

## 수치 조정 기록 (최근)
- 추가 탄환: 한 발 피해 J×4 → J×0.9, 튕김·수명 감소, 탄속 = `clamp(450 + J×0.25, 500, 2000)` (충돌 세기 비례)
- 연쇄 번개: 피해 = 충돌 충격량 × (1 + 0.5(Lv−1)), 재발동 0.15초
- 자동 발동 무기 ×0.6 (`PAS`)
- 위성 계열 +30%, 지뢰 계열 +30%, 블랙홀 폭발 −30%
- 레일건 ×2, 굵기 4배 / 항성 핵 −10%
- 적 폭발(폭탄병·엘리트)로 적이 받는 피해 ×0.1
- 지뢰: 크기와 무관하게 일정 간격 매설 (Lv1 1초 → Lv5 0.6초), 30초 유지, 최대 개수 = 30초 분량
