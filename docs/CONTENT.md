## 무기 (슬롯 4칸)

| 키 | 이름 | 최대 Lv | 설명 |
|---|---|---|---|
| `aura` | 자기장 | 5 | 내 몸 주위에 전기장. 안에 든 적은 느려지고 계속 피해를 입음 (클수록 범위가 넓음, 레벨마다 범위·피해·감속 증가) |
| `fire` | 화염 궤적 | 5 | 빠르게 달리면 지나간 자리에 불길이 남아 적을 태움 (레벨마다 불길 크기·지속·피해 증가) |
| `missile` | 유도 미사일 | 5 | 주기적으로 가까운 적을 쫓는 미사일 발사. 맞으면 작은 폭발 (레벨마다 발 수·폭발 증가) |
| `mine` | 지뢰 | 5 | 지나간 자리에 일정한 간격으로 지뢰를 깔아둠. 적이 밟으면 폭발 (레벨마다 매설 속도·개수·폭발 증가) |
| `chain` | 연쇄 번개 | 5 | 세게 부딪히면 번개가 주변 적에게 튐 (레벨마다 튀는 수·피해 증가) |
| `shrap` | 추가 탄환 | 5 | 세게 부딪히면 사방으로 탄환 발사. 세게 박을수록 탄환이 빠르고 셈. 벽·바위·적에 튕기며 피해 (레벨마다 탄 수·튕김 횟수 증가) |
| `hole` | 특이점 | 4 | 튕겨 날아간 적이 다른 적과 부딪혀 피해를 주면, 그 자리에 일정 확률로 블랙홀 생성 (레벨마다 확률·크기·동시 개수·흡입력 증가) |
| `orbit` | 위성 | 4 | 주위를 도는 위성이 적을 쳐냄 (레벨마다 위성 +1) |

## 특수 능력 (5·15레벨에 3개 중 1개, 최대 2개)

| 키 | 이름 | 설명 |
|---|---|---|
| `nova` | 초신성 | 죽을 만큼의 피해를 받으면 대신 대폭발하고 HP 절반 회복. 재충전 120초 |
| `dense` | 밀도 압축 | 크게 커진 상태에서 순식간에 최소로 줄이면, 2초 동안 큰 질량을 지닌 채 작고 빠른 몸이 됨. 재충전 8초 |
| `well` | 중력 우물 | 커지기 시작하는 순간 주변 적을 내 쪽으로 끌어당김. 재충전 4초 |
| `absorb` | 질량 흡수 | 적을 처치할 때마다 최대 크기가 조금씩 늘어남 (최대 +30%). 피해를 입으면 일부를 잃음 |
| `elastic` | 탄성 충돌 | 들이받은 적이 버티면 속도를 잃지 않고 반사되어 튕겨 나감 |
| `tidal` | 조석력 | 클 때 몸 가까이 있는 적이 조석력에 찢겨 계속 피해를 입음. 가까울수록 급격히 강함 |

## 진화 28종 (두 무기 최대 레벨 → 슬롯 1칸으로 합쳐짐)

| 키 | 이름 | 재료 | 효과 |
|---|---|---|---|
| `chain+shrap` | 번개탄 | 연쇄 번개 + 추가 탄환 | 탄환이 전하를 띰. 가까운 탄환끼리 번개 줄로 이어지고, 줄에 닿은 적이 감전 |
| `chain+hole` | 뇌운 특이점 | 연쇄 번개 + 특이점 | 연쇄 번개에 맞은 적마다 약한 블랙홀이 생김 |
| `chain+orbit` | 뇌전 위성 | 연쇄 번개 + 위성 | 연쇄 번개에 맞은 적 주위에 번개로 이어진 위성 3개가 돌며 따라붙음 |
| `chain+aura` | 폭풍 코일 | 연쇄 번개 + 자기장 | 번개가 지나간 선을 따라 넓은 캡슐 모양 자기장이 5초 남음. 겹친 영역은 하나로 합쳐짐 |
| `chain+fire` | 플라즈마 화염 | 연쇄 번개 + 화염 궤적 | 번개가 지나간 궤적에 화염 자국이 남음 |
| `chain+missile` | 낙뢰 미사일 | 연쇄 번개 + 유도 미사일 | 미사일이 터진 자리에서 번개가 튐. 번개 근처의 미사일은 크게 가속 |
| `chain+mine` | 전격 지뢰 | 연쇄 번개 + 지뢰 | 연쇄 번개에 맞은 적 바로 아래에 지뢰가 심어짐. 지뢰가 근처 적에게 천천히 다가감 |
| `shrap+hole` | 지평선 탄 | 추가 탄환 + 특이점 | 추가 탄환 대신 블랙홀 6개가 탄환처럼 날아가다 끝에서 터짐 |
| `shrap+orbit` | 파편 고리 | 추가 탄환 + 위성 | 탄환마다 위성 2개가 계속 돌며 같이 날아감 |
| `shrap+aura` | 대전 탄환 | 추가 탄환 + 자기장 | 탄환 주위에 작은 자기장. 탄환에 맞지 않아도 근처만 지나가면 피해와 감속 |
| `shrap+fire` | 소이탄 | 추가 탄환 + 화염 궤적 | 탄환이 지나간 자리에 불길이 남음 |
| `shrap+missile` | 집속 미사일 | 추가 탄환 + 유도 미사일 | 탄환이 적을 맞힐 때마다 그 자리에서 유도 미사일이 생김 |
| `shrap+mine` | 파편 지뢰 | 추가 탄환 + 지뢰 | 탄환이 지나간 길에 띄엄띄엄 지뢰를 묻음. 내가 깐 지뢰는 터질 때 탄환을 흩뿌림 (이 탄환은 지뢰를 안 묻음). 지뢰가 근처 적에게 천천히 다가감 |
| `hole+orbit` | 강착 원반 | 특이점 + 위성 | 주기적으로 위성 하나를 적에게 던지고, 떨어진 위성이 블랙홀이 됨 |
| `hole+aura` | 자기 붕괴 | 특이점 + 자기장 | 블랙홀이 생길 때 넓은 자기장도 함께 생기고, 블랙홀이 터진 뒤에도 5초 남음. 모든 자기장 안에는 약한 인력 |
| `hole+fire` | 항성 핵 | 특이점 + 화염 궤적 | 블랙홀이 터질 때 불 고리가 퍼져 나가고, 그 자리에 불바다가 남음 |
| `hole+missile` | 중력 탄두 | 특이점 + 유도 미사일 | 미사일이 터진 자리에 블랙홀이 생김 |

| `orbit+aura` | 전자 고리 | 위성 + 자기장 | 자기장이 넓어지고 피해 대신 사냥터가 됨. 위성 10개가 흩어져 자기장 안의 적을 각자 추격 |
| `orbit+fire` | 태양 위성 | 위성 + 화염 궤적 | 위성이 불꽃 나선을 남기고, 1.5초마다 불 고리를 내뿜음 |
| `orbit+missile` | 호위 편대 | 위성 + 유도 미사일 | 미사일마다 위성 4개가 돌며 호위. 미사일이 터지면 위성은 그 자리에 잠시 남음 |
| `orbit+mine` | 궤도 기뢰 | 위성 + 지뢰 | 위성이 근처 적에게 지뢰를 던져 묻음. 지뢰가 근처 적에게 천천히 다가감 |
| `aura+fire` | 플라즈마 장막 | 자기장 + 화염 궤적 | 자기장 안에 들어온 적을 중심으로 불의 원이 생겨 주변 적까지 계속 태움 |
| `aura+missile` | 레일건 | 자기장 + 유도 미사일 | 미사일 대신 굵고 강한 레일건 한 발. 줄 위의 적을 모두 꿰뚫음 |
| `aura+mine` | 전자기 지뢰 | 자기장 + 지뢰 | 지뢰가 터진 자리에 최소 크기 때와 같은 자기장이 4초 남음. 지뢰가 근처 적에게 천천히 다가감 |
| `fire+missile` | 화염 미사일 | 화염 궤적 + 유도 미사일 | 미사일이 지나간 길에 불길, 터지면 불 고리가 퍼지고 불바다가 남음 |
| `fire+mine` | 화염 지뢰 | 화염 궤적 + 지뢰 | 지뢰가 터지면 불 고리가 퍼지고, 그 자리와 주변에 불 장판이 생김. 지뢰가 근처 적에게 천천히 다가감 |
| `missile+mine` | 연쇄 기폭 | 유도 미사일 + 지뢰 | 내 지뢰가 적을 감지하면 미사일을 쏘는 포탑이 되고, 다 쏘면 스스로 터짐. 지뢰가 근처 적에게 천천히 다가감 |
