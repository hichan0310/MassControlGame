# 게임 설계

## 컨셉
붕괴하는 성운 속 원시별 하나. 같은 물질을 두고 경쟁하는 가스 덩어리·갈색왜성·떠돌이 행성이 사방에서 몰려온다. 플레이어는 **크기(질량)를 조작해 운동량으로 들이받으며** 살아남는다. 죽으면 별이 터지며 흩어지고 "파괴되었습니다" 화면과 딜 기여도가 뜬다.

메커니즘은 그대로 두고 이름·연출만 성운 테마로 맞췄다(소닉붐 → 체렌코프 빛, 경험치 → 성간 가스 등).

## 핵심 손맛 (가장 중요)
1. **작게 줄여 가속한다.** 작을수록 최고 속도·가속이 크다. 작을 때만 크기 에너지가 충전된다.
2. **부딪히기 직전에 커진다.** 크기를 바꿔도 속도는 유지되므로, 빠른 채로 무거워진다 → 큰 충격량.
3. **무리를 뚫는다.** 튕겨난 적이 다른 적에게 부딪혀(당구) 연쇄 피해를 낸다.
4. 커져 있으면 에너지가 닳는다 → 다시 작아져서 충전하는 리듬.

무기와 진화는 이 손맛을 **키워 주는 쪽**이어야 한다. 충돌로 발동하는 무기는 충돌 세기에 비례하고, 저절로 발동하는 무기는 화력을 0.6배로 낮췄다.

## 물리 (주요 수치)
| 항목 | 값 |
|---|---|
| 화면 / 줌 / 맵 | 논리 화면 960×600, 줌 0.6 (월드 1600×1000이 보임), 맵 5600×3600 |
| 질량 | `mass(r) = (r/0.64)² / 100` |
| 크기 범위 (시작) | 반지름 5 ~ 41, 변화 속도 140/s |
| 최고 속도 | `600 × (14/r)^0.6 × 속도배율 × (1 + 0.012 × (레벨−1))`, 절대 상한 2200 |
| 가속 | `1900 × (14/r)^0.9 × 속도배율` |
| 크기 에너지 | 최대 100, 작을 때(크기 40% 미만)만 초당 45 충전, 클 때 `26 × t²`/s 소모, 0이면 과부하(강제 축소, 35까지 차면 해제) |
| 충돌 | 반발계수 0.3. 충격량 `J = 1.3 × 접근속도 / (1/m1 + 1/m2)` |
| 적이 받는 피해 | J × 피해 배율. 단 적이 부서질 만큼만 전달 |
| 내가 받는 피해 | 내 속도 변화량 × 0.12 를 `10 × (d/10)^0.7` 로 완화, 한 번에 최대 체력 60% 상한 |
| 체력 | 최대 체력 `(100 + 8 × (레벨−1)) × 강체 배율`, 초당 `(6 + 재생) × (1 + 0.045 × (레벨−1))` 회복 (최대 체력 증가율의 약 56%) |
| 충돌 회복 | 몸으로 들이받아 부수면 최대 체력의 `1.2% × clamp(J/1500, 0.5, 2)` 회복 (무기·당구 처치는 제외) |
| 관통 | 0.5초 안에 몸으로 연속 처치한 수 n. 처치한 적의 구슬 값 `× min(2.5, 1 + 0.1n)` |

## 체렌코프 빛 (구 소닉붐)
- 성운은 굴절률 2의 매질 → 성운 속 빛의 속도 `MACH = 1150` (= 0.5c, `C_LIGHT = 2300`).
- 플레이어는 0.012초마다 파면(원)을 내보낸다. 연속한 두 파면의 교차점을 이은 선이 원뿔이 되고, **보이는 선과 피해 판정이 같다.** 속도가 MACH 를 넘을 때만 교차가 생기므로 자연스럽게 원뿔이 나타난다.
- 1레벨에서 가장 작아도 최고 속도 약 1110 → 레벨·추진력·극소화로 넘어야 한다.

## 적
| 종류 | 반지름 | 기본 체력 | 속도 | 특징 |
|---|---|---|---|---|
| 추격자 | 8 | 400 | 150 | 기본 |
| 떼거리 | 5 | 120 | 250 | 빠르고 약함 |
| 방패병 | 18 | 6000 | 85 | 무겁고 단단함 |
| 돌진병 | 10 | 1500 | 110 | 조준 후 돌진 |
| 사수 | 9 | 600 | 110 | 탄 발사 |
| 폭탄병 | 11 | 500 | 120 | 죽으면 폭발 (적이 받는 폭발 피해는 1/10) |
| 가시 | 12 | 900 | 100 | 닿으면 나도 아픔 |
| 분열체 | 15 | 1200 | 95 | 죽으면 갈라짐 |
| 거대 엘리트 | 34 | 30000 | 70 | 죽으면 큰 폭발 |

- **체력 배율(시간)**: `1 + 0.3m + 0.05m²` (m = 분). 5분 ×3.8, 10분 ×9, 15분 ×16.8. 튜토리얼 중에는 배율 없음.
- **종류 비중**: 시간이 지날수록 방패병·돌진병·가시·분열체 비중이 커지고 추격자가 줄어든다.
- **스폰**: 1초마다 무리(최대 14마리), 동시 상한 `min(230, 50 + 0.8t)`. 45초마다 주제가 있는 물량 공세, 40초마다 엘리트(첫 등장 1분 30초, 5분마다 +1), 1분 이후 18초마다 한 방향에서 중장갑 분대.

## 성장
- **레벨업 카드 3장** 중 하나. 처음 준비된 진화는 반드시 1장 포함, 한 번 넘긴 진화는 35% 확률로 다시 등장. 무기 슬롯 여유가 있으면 무기 1장 보장.
- **무기 8종 (슬롯 4칸)**: 연쇄 번개, 추가 탄환, 특이점, 위성, 자기장, 화염 궤적, 유도 미사일, 지뢰.
- **진화 28종**: 두 무기를 최대 레벨로 올리면 진화 카드가 나오고, 고르면 슬롯 1칸으로 합쳐진다. 진화에 쓰인 무기는 다른 진화의 재료가 될 수 없다 → 최대 진화 2 + 무기 2, 또는 진화 4.
- **특수 능력 6종**: 5·15레벨에 일반 카드 대신 3개 중 1개, 최대 2개 (초신성, 밀도 압축, 중력 우물, 질량 흡수, 탄성 충돌, 조석력).

## 진화 설계 원칙
진화는 "A가 발동하면 B의 작은 효과가 터지는" 식이 아니라, **한 무기가 다른 무기의 작동 방식 자체를 바꾸는 것**이다.
- 매개체: 한쪽이 다른 쪽이 흐르는 길이 됨 (번개 궤적에 화염 자국, 탄환끼리 번개 줄)
- 힘: 한쪽의 힘이 다른 쪽을 휘게 함 (블랙홀이 탄환처럼 날아가며 적을 끌고 감)
- 연결·기폭: 한쪽이 다른 쪽을 잇거나 터뜨림 (지뢰가 포탑이 되어 미사일 발사)
- 불을 "내뿜는다"는 것은 **퍼져 나가는 불 고리**를 뜻한다 (불을 소환하고 끝나는 게 아님).
- 지뢰가 들어간 진화를 가지면 지뢰가 근처 적에게 천천히(초속 120) 다가간다.

## 화면·UI
- 왼쪽 위: 레벨, 처치 수, 무기 칸 4개(아이콘 + 레벨 칸, 진화는 합쳐진 아이콘), 특수 능력 칸 2개(금색).
- 카드: 큰 아이콘 + 이름 + 상태(새 무기 / Lv a→b / ★진화 / 특수 능력) + 설명.
- 결과 화면: 생존 시간·레벨·처치·점수·최고 충격량·최고 생존 + **딜 기여도**(아이콘·이름·막대·피해량·비율, 진화는 진화 이름별, 진화에 쓰인 무기 피해는 진화 몫).
- Esc 설정: 전체 볼륨, 화면 흔들림(0~100%), 화면 번쩍임(켜기/끄기), 6개 동작의 키 2개씩 재지정, 초기화, 처음부터. 창을 벗어나면 자동 일시정지.
- 개발자 모드(`hichanplay`): 시간 이동(그 시점 적 체력·종류·수로 즉시), 레벨 올리기(카드 있음/없음), 무적, 회복, 적 제거, 무기 레벨 자유 조절(슬롯 제한 없음), 특수 능력·진화 켜고 끄기.
- 튜토리얼: 이동 → 작아지기 → 커지기 → 뭉친 적 10마리 처치. Enter 로 건너뛰기, 튜토리얼 중에는 죽지 않음.

## 연출 규칙
- 빛 효과는 미리 그린 방사형 그라데이션을 '더하기' 합성으로 그린다(`glow`). 적은 빛나지 않고 어두운 테두리, 경험치는 빛나는 민트·금색 반짝이 → 구분이 쉽게.
- 불 계열은 1/3 해상도 별도 캔버스에 '밝은 쪽만 남기는' 합성으로 그린 뒤 한 번에 얹는다 → 겹쳐도 하얗게 안 뭉치고 가볍다.
- 카메라 흔들림 상한 12px, 효과음은 종류별 동시 재생 상한(넘치면 가장 오래된 소리를 끊고 재생).
- 화면 글자 배너·슬로모션 없음.
